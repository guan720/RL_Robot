## 什么值得保留

- 核心代码、配置、数据契约、环境锁、成功判据、最终模型与其 normalizer。
- 关键对照、逐局评测、失败分类、预注册方案和改变结论的反例。失败实验不等于无用文件。
- 后续学习所需的示范、纠正片段和原始观测；暂未查清依赖的中间 checkpoint/replay。
- 被代码读取的 Markdown 和源码备份。目前部分门禁依赖文档，仍原位保留。

## 什么移出日常入口

- 历史 PID、ETA、排队心跳、重复广播、逐条销账和哈希串。
- 已完成交接的过程文档：无代码引用的移入归档；有引用的暂时保留。
- 日报和最小路线 README 的旧全文保留一份归档，不继续逐条追加到阅读入口。

后续日报只写四项：完成、结果、阻塞、下一步；每个数字注明分母、判据和来源。详细实验材料留在实验目录，避免在日报、交接单、README 中复制三遍。
