## 范围和判据

- 仿真：robosuite PickPlaceCan / Panda，单臂、单 can，正向托盘→篮格，反向篮格→托盘。
- 输入：两路 RGB、8 维末端/夹爪状态；动作：7 维 OSC_POSE 增量与夹爪。
- 20 Hz，同步执行；π₀.₅ chunk_size=50，当前多数主结果用 K=10 重规划。K=1 的精度优势伴随明显推理超时；K=50 尚需核实关门配方结果。
- 严格成功包括送达、松手、落定和保持；反向还要求倾角 <20°。放宽口径只取消反向倾角要求，侧躺单独标记，不等于“曾进入目标框”。
- Harness 是确定性检测器与脚本专家，不是 LLM。检测能力和脚本恢复依赖仿真信息，不能直接宣称可部署真机。
- **夹爪符号以代码常量与探针为准：+1 闭合、−1 张开。** `mg_env.py` 顶部旧注释有相反表述；接真机必须重新实测，不能照抄。

## 运行约束

环境入口是 [code/env.sh](code/env.sh)，面向原 Linux 服务器的独立 venv。Windows 本地目录是下载副本，不保证直接运行。
本目录不 import 仓内其它路线；数据和环境保持隔离。运行前按脚本 `--help` 核对参数及本机路径，不直接执行历史排队脚本。

## 尚待核实或推进

1. 档 9C、10、11：文档只记录排队/起跑，须读最终判定文件确认。
2. 侧躺、接触弹射、夹持中断：按失败类型分析，不能仅靠最大抬升高度判抓住。
3. 残差 RL：补完整视觉 transition、真实执行动作与奖励、终止/截断标记，并与动态纠正 BC 同预算比较。
4. 真机：本路线无 Piper 驱动、标定或物理验证；通过独立 adapter/Gateway 对接，先单臂再双臂。

源码备份中有回归测试依赖，如 `mg_env_reverse.py.bak_pre_relax`，不可按扩展名直接删除。历史原件里的行号、旧状态和计划不代表当前代码或服务器状态。
