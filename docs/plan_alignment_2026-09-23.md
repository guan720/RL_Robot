## 0. 结论先行

调研与我们的实测数据指向同一句话：**瓶颈不在算法，在研究任务的分辨力与约束的真实性**。
理想环境里 SAC 打平脚本（98.6% vs 98.6%）→ 加扰动后差距可测（67.8% vs 84.1%）→
换到 robosuite 接触物理后稀疏奖励下 SAC 100k 步 0%。**每加一档真实约束，问题才重新可判定**；
单纯换大模型或换 RL 算法证明不了任何东西。

因此平台搭建测试阶段的「对齐前沿」不是追最新模型，而是对齐四件事：

1. **问题结构**：reset-free + 恢复调度是 2026 年活跃前沿（MEDAL++ → RoboClaw → REVERSAL-BENCH），
   而我们已经有测量仪器（36 格覆盖 / 起始熵 / 内生占比 / 救场与复位记账）——这是本项目的差异化位置。
2. **单卡算力的主流答案**：冻结大策略、只学小模块（residual / RLT / Q-Planning）。
   我们的「脚本上界 84.1% vs SAC 67.8%」差距正是残差公式的土壤。
3. **数据混合**：RLPD / HIL-SERL / RECAP 一脉。我们的示范预填已实测 +27 点（150k 臂），
   下一步把它正式化：混合比扫描 + 失败数据的利用。
4. **实验口径**：调研 §7 直接变成我们的报告模板（冻结保留测试集、能力与成本同报、
   reset-free 相邻任务不算独立样本、seed 级区间）。

## 3. 平台搭建测试阶段与「前沿」的对齐方式

调研的四层表（Policy / Learning / Harness / Environment）与我们接口一一对应：
`skills/` = Policy 槽、`harness/trainer.py` = Learning 槽、`harness/ + registry/` = Harness 槽、
`envs/ + G2 IK` = Environment 槽。**对齐的操作含义是：每层留可替换插槽，一次只换一层**
（调研 §4.4 的警告：不要同时换数据、环境、策略表示和算法再归因）。

当前每一层该对齐到什么程度：

- **Policy 层**：SAC/MLP 与脚本控制器足够；像素档用 SB3 CnnPolicy 先量「视觉的代价」；
  VLA（SmolVLA）只在 RGB 基线阶段进入，且先测工程链（格式/归一化/延迟）再谈微调。
- **Learning 层**：把「示范预填」升级成正式的离线+在线混合（RLPD 式）：混合比、失败数据、
  接管轨迹记账（调研 §4.1 的纪律：接管 transition 不能写成自主 action）。
- **Harness 层**：这是本项目与 2026 前沿重合度最高的一层。RoboClaw/ENPIRE/ASPIRE/RoboRSI
  都在回答「何时执行、恢复、训练、验证、发布」；我们的差异化是**把恢复调度当成可测量变量**
  （覆盖/熵/内生/救场记账已就位），假设 A 就是这一层的独立研究问题。
- **Environment 层**：robosuite 近期主力（调研 §6.4 与本机的渲染实测一致）；ManiSkill3/Isaac
  等需要 GPU 并行渲染时再评估；Genie Sim 只按团队节点条件推进。

## 4. 立即实验队列（按优先级，含决策点）

1. ✅ **PickPlaceCan state：稀疏 vs shaped**。两臂 100k 均完成，修复成功口径后重评都 0%；
   shaped 臂 mean_reward 1.09→9.19（重评 12.28）说明学到 reach/grasp/lift/hover 而没学到 place。
   决策点已触发（shaped <10%）→ 直接上示范预填，不再调 SAC 超参。
2. ✅ **脚本式 pick-place 控制器**：`scripts/demo_scripted_pickplace.py`，5/6 成功（含一次
   掉落重抓恢复），成功视频已存。下一步把它接成示范预填的示范源（队列 3 的前置已就绪）。
3. **示范预填臂 + 混合比扫描**（0/5k/10k/20k/40k；抽象环境已有部分点，补成曲线）。
   链路已通：`train_pickplace_sac.py --demo-steps N` 调 `demo_scripted_pickplace.py` 的控制器
   预填回放池（SB3 2.x `replay_buffer.add` 需 batch 维）。冒烟 2k+500 步通过；
   正式臂 10k 示范 + 100k shaped **已完成：冻结/重评成功 0%，重评奖励 7.54 < 无示范臂 12.28**
   → 示范在接触物理任务里连「点火」都没点着（抽象环境里 +27 点的结论不外推）。
   **混合比扫描在 robosuite 上补 5k/20k/40k 三点**，验证阶段 2 的「示范是点火器不是燃料」
   （40k 反而更差）在接触物理任务上是否同样成立。**降级：先解「能不能学会」（见 3.5），再谈混合比。**
3.5 **课程阶梯下移：Lift shaped 60k**（`--task lift`，在跑）：移动-抓-提起、无放置段，
    回答「这套栈能否把接触任务成功率从 0 训上去」。决策点：冻结成功 >0 且曲线上升 →
    回 PickPlaceCan 加 BC 锚定/拐杖；仍 0 → 先查栈本身（OSC 带宽、观测完整性、奖励尺度），
    而不是继续换任务或加拐杖。
    **终判（从零臂）**：终冻结 5 局 40% 是**小样本错觉**，20 局重评 **5%（1/20）**、mean_reward 107.5
    （会接近/贴住 cube 但几乎不提起）；训练中 [0,20,0,0,0,0]%。判别实验 `demo_scripted_lift_rs.py`
    6/6（~48 步提起）先排除了栈问题
    （初版 0/6 是夹爪语义写反，见 `notes_vision.md` 坑清单）。对照臂 demo5k+60k 在跑：
    若预填臂明显更稳 → 示范预填在接触物理里有效（PickPlaceCan 的 0% 归因于任务超预算）；
    若同样抖 → 上 **BC 锚定**（先用示范做行为克隆热启动再 RL，SERL/RLPD 的标准做法），
    而不是加示范量或加 seed。**BC 臂已排队并在跑**（`--bc-steps 3000`，冒烟 500 步 reward 7.48
    vs 无 BC 0.35）：三臂对照 从零 / 预填 / 预填+BC，一次只加一个变量。
4. **残差三臂对照**（base-only / 从零 SAC / base+有界残差；同预算同观测，扰动环境）。
5. **阶段 2 扩展**：恢复目标选择 5 臂 + 不可恢复状态变体 + slow-drift 扰动档。
6. **统计口径改造**：seed 级 min/max、最终保留测试集、成本列进主表。
