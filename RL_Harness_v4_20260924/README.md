## 接收与使用

1. 将整个 ZIP 解压到独立目录，不要只转发三篇 Markdown。建议 Windows 使用较短路径，如 `D:\work\RL_Harness_v4_20260924`。
2. 用 Markdown 编辑器打开本页。正文插图为本地 SVG，同时保留 PNG 和 Mermaid 图源；读取文档与图示无需联网。
3. 可选：在包根目录执行 `python -B tools/verify_package.py`。需要 Python 3.10 或以上标准库，无需安装第三方依赖；命令只做文件和链接核验，不联网、不调用 GPT、不连接机器人。
4. 团队按阅读索引分工，把实际参数写入 `work/`、代码写入 `implementation/`。这两个目录只有使用说明，尚无机器人软件实现。

```text
RL_Harness_v4_20260924/
  README.md                  接收入口
  AGENTS.md                  本包新增的 Codex 接手上下文
  guides/                    阅读、实施、Codex、版本说明
  templates/                 待填写参数、阶段进度、验收记录
  materials/                 原文、图、来源、历史依据与审查报告
  audit/                     原文件身份、快照映射、打包审查
  tools/verify_package.py     独立离线校验器
  implementation/            后续代码位置，目前未实现
  work/                      后续测量、决策和验收记录位置
  MANIFEST.json              交付文件清单与 SHA256
```

主方案始终是 `materials/06_…`。`02–05` 是引用所需的历史材料，旧文中的“当前／最新”仅指其当时版本。`07` 是独立的 EGO 监督扩展讨论，未并入 v4，不能因日期较新就替代主方案。

本包不依赖原聊天记录、原工作区或科学家知识库。外部论文、远端仓库的完整安装、模型权重、数据与 API 仍需实施时按选定路线取得并锁定版本。包内上游源码摘录仅供审计，不是完整可运行仓库。
