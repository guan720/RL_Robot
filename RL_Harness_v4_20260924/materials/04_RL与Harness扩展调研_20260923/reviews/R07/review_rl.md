## 逐项质询

1. **零自主成功是否被改成必须先有高成功率 base？—PASS。** T01:5–7、39、266–279；V:115。允许少量 BC 与局部可靠纠正，没有保证全零奖励且无有效纠正也能启动。RT-EXPO 原文要求先达到约30%成功只是作者实验条件，冻结稿未移植为用户门槛。[原文 S5][S5]

2. **反向是否真的更新同一 θ，而非独立 reset policy？—PASS。** T01:90–109；T02:221–225、333、340。actor/Q/target/BC/reward/replay 共用 goal 身份，双向分层与同 checkpoint 发布；换向切 episode。源码平台本身不证明该组合，稿件已列为新增验收。[平台源码 S4][S4]

3. **Harness-DAgger 是否只是存成功轨迹，或假定完美教师？—PASS。** T01:39–41、133–141、281–285；A:169–184。访问状态持续标注、可靠局部 BC 与真实后果 RL 分开；不把 GPT 置信或整回合成功当全部动作真值。DAgger 的专家与学习条件不能自动扩展成 GPT 保证，文档明确承认这一点。[算法 S3][S3]

4. **纯标签是否会借别人的后继伪造 TD？—PASS。** T02:205–217、253–257；T06:65–95。shadow 只进监督池；实际 request 准时形成 next queue 才具普通 TD 资格。未物理激活并非一律无转移：队列改变是定义中的真实环境后果。这是本项目推导，不能冒称 DAgger 原定理。[监督依据 S3][S3]

5. **当前旧 C 的回报配新 U，是否错位？—PASS。** T06:42–61、79–85、107–148。对 X=(h,g,C,ξ)，本槽执行 C，U 令 C_next=U；因此 R_n+γ^nQ(X_next,π(X_next)) 是相邻决策备份。未偷移下一槽奖励，γ 的微步/槽单位明确；与 SmoothRL 的2n目标明确分开。上述成立性是对拟议队列模型的审查推导。[对照 S1][S1]

6. **C/E/D 梯度是否只靠事后 mask？—PASS。** T06:152–190、286–292；T02:243–257。真实 C 是状态，Q 动作路径只经 E，D 排除；BC mask、物理执行与 TD 资格独立。共享参数仍可能改变其他输出，稿件没有作错误数值不变承诺；部分 flow 标签也没有仅乘 loss mask 就宣称兼容。[原理 S1][S1]

7. **C 内真终局、U 尚未提交时会丢正奖或虚构动作吗？—PASS。** T06:194–231、294–298。仅原事前请求在冻结输入下完成的 U 配 R_L，未知动作不补造；terminal 不 bootstrap，该行不做 actor Q 更新。正奖沿既有一步链传播，不按未来成功改前驱。actor 存活筛选偏差已明示；这是项目终局规则，不是已获原论文实证。[并发依据 S1][S1]

8. **抢占、超时删失是否被写成失败零价值？—PASS。** T06:221–255、304–310；T01:247、285。受影响宏槽隔离，准确前驱保留，不把后续接管动作倒填旧队列；同时承认干预选择偏差与覆盖缺口。保留微步事实并不自动证明宏 TD 合法。[时序对照 S2][S2]

9. **完整头是否被预设胜过原生头/编辑？—PASS。** T01:264–279；R:209–215；V:121–152、275–286。加入原生 TD3＋BC 与 RT-EXPO，先看可靠纠正覆盖及小预算 BC；不把零成功等同候选无覆盖。RT-EXPO 的有界编辑、原生 BC 与本项目不同时间协议已分开，未宣称换名称即可共用 replay。[机制 S5][S5]

10. **确定性完整头能否直接复用默认 SAC worker？—PASS。** T02:397；P:35、94–100。固定 RLinf 源码的常规分支求和 reward、用一次 discount，actor 有 αlogπ，另有温度更新；不是 T06 目标。稿件要求替换 actor/target/熵接口并新增独立 BC 标签分支，没有用假 logπ 满足签名。[固定函数 S4][S4]

11. **对照的信息与总成本是否公平？—PASS。** T01:275–277；T02:T34（381）；R:205、211–213；V:136–158、279–285。逐模块列图像历史、派生状态、可用时间和计算成本，区分自然延迟与注入；同纠正/示范/实体预算并评 policy 独立能力。RT-EXPO 的任务输入和有限实验预算不被当作用户设备结论。[实验 S5][S5]

12. **通用性是否被某品牌适配替代？—PASS。** T01:11、271–273；T02:387–395；H:194–206。能力/schema/adapter、不同维度回放与旧 replay 隔离明确，硬件支持只计移植成本。平台、学习方法与 Harness 分层验收；没有从平台 action_dim 或支持表推出跨本体共享权重。[源码边界 S4][S4]
