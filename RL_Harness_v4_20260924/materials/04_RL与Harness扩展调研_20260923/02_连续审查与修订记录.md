# 本次扩展调研的独立连续审查

2026-09-23｜最终状态：**完成连续三轮无必要修订的独立审查**。

本次共进行 11 轮，每轮启动三名新的独立审查 agent；共 33 份正式审查报告、456 项逐项问题。必要修订及主动采纳的选型扩展均重新冻结并重置连续通过计数；最后 **R09、R10、R11** 在相同的九份输入上连续通过，共 108 项问答。问题可跨轮重复，不把它们宣称为同样数量的不重复技术发现。R05、R07各另有两项有界源码／适配补核，不计作正式审查轮次。

通过仅表示在本次文档、来源和兼容性审查范围内未发现还需修改的问题。没有实施框架集成、模型训练、真机试验，也不证明全领域无遗漏或无人工学习已经实现。旧 v2 的审查不抵充本次。

## 2. 找到的问题与实际修正

| 发现轮次 | 问题 | 修正 |
|---|---|---|
| R01 | RT-EXPO 延迟实验条件不完整 | 分开 wall-clock 注入与 chunk-delay，保留 Dynamic Picking 例外，要求测真实部署时延 |
| R02 | 普通 SFT 42% 与 RTC-SFT 60% 的参照未明确 | 在效果附近并列基线及 RT-EXPO 约97%，注明四任务均值与试次数 |
| R02 | rollout 无动作干预易被误读成无人复位／验收；十分钟预算含义不足 | 明确人工复位和人工验成功，十分钟为在线数据而非全部墙钟成本 |
| R04 | RT-EXPO 派生状态与图像历史未完整进入实验条件／比较协议 | 补齐模块信息来源、可用时间、预处理成本与共同信息／输入消融要求 |
| R05 | 三份审查均通过后，根审主动采纳补漏并扩展候选池 | 固定源码核查后纳入 OpenETA；归并 Harness VLA／RPent；补资产边界并重写通用接口比较，因此不累计本轮通过 |
| R07 | RAPolicy 初查未确认代码，追加原始入口与源码核验后发现实质训练实现 | 晋升原生头预检候选；补 hold／队列、latent／真实示范、价值提取与接管兼容性，重新冻结并归零；另澄清投影动作接口 |
| R08 | VLA 专题开头仍是新增原生候选前的两路摘要 | 根审采纳可读性建议，同步摘要与候选地图，避免单独阅读遗漏 RAPolicy；重新冻结归零 |

修订期间还采纳了十示范 RECAP 补漏、actor terminal 过滤的状态采样权重说明、SAC 概率接口与确定性目标分离、C 符号区别和核心术语解释。所有这些修改都在最后三个通过轮次之前冻结，没有审后偷偷改变技术正文。
