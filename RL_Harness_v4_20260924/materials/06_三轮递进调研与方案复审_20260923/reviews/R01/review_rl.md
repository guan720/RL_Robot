## 3. 逐问审查

### Q1：同 θ 双向是否只是口号，或由两个模型各自完成？

**位置：**D §5、§10.4、§13；I §2.3、§5.2、§6.1、T17/T24；E §1.2、§2.2。**已读证据：**冻结正文及 I；P2 的条件化状态机制用于交叉理解，不作为双向迁移效果证据。

**判断：充分。** goal 贯穿 actor/Q/target、BC、reward、replay 与 Harness；两个方向分层采样、一个 checkpoint 共同发布，正常反向均接受 RL 和纠正。独立参数仅在 H2 消融出现。共享迁移可能退化，文档没有保证收益。

**反例核对：**同一物体位于 B 时，g=B 与 g=A 的终止／价值语义相反；仅换 prompt 而 Q 不看 goal 会混淆。D §5 与 T17 已明确排除；A §12 又把检查扩展到 editor/filter/predictor 全包。**必要修改：无。**

### Q2：低起点时，是否把“多失败几次”当作自动学习来源？

**位置：**D §1–3、§6.2–6.3、§9、§10.2、§12；E §1.2、§2.5、§3.3；调研 §12。**已读证据：**上述冻结材料，S3 §3–4；P3 的编辑范围与选择分支。

**判断：充分。** 少量示范、可信局部纠正、探索／奖励覆盖构成启动条件；完整头的自由度不被等同于少数据可学，零次成功也不被等同于候选支持严格为零。预检分别检查候选出现、编辑可达、Q 排序、BC 后独立闭环，并允许切回原生动作先验。

**反例核对：**所有 base 候选都不能张爪、编辑幅度又跨不过阈值时，仅增加 Q 更新无法补足动作支持；相反，有限 N 没找到好动作并不能证明理论支持为零。D §10.2 已给出对应取舍。Harness 尚未证明可靠是待实验问题，文档已明示，不能因此强制新增强教师。**必要修改：无。**

### Q3：部署 policy 是否完整，独立评估是否会偷偷保留 GPT 代做？

**位置：**D 引言第 13 行、§11、§13；I §6.1–6.2；E §2.1、§3.1。**已读证据：**冻结部署定义；P1 的冻结底模＋学习附加网络实例，P3 的编辑／Q 选择过程。

**判断：充分。** 预声明的原生头、完整头、editor／Q 筛选器可以构成部署包，必须共同冻结、计成本和时延；训练专用 Q 与执行必需 Q 区分。独立评估关闭 Harness 临场动作帮助，仍保留共同本地保护。原生 VLA 参数内化与复合包变强分开报告。

**反例核对：**底模不更新、编辑器学会纠正时，完整包可有学习收益；若只测包后声称底模已内化，归因错误。当前文字已禁止该推论。反过来，评估时剥掉方法必需编辑器也会换成另一个 policy；当前清单阻止此误测。**必要修改：无。**

### Q4：一槽 queue-MDP 的状态、动作和 target 是否自洽？

**位置：**D §8.1–8.2；A §1–3、§9 例1、§10；I §5.3、T10/T13。**已读证据：**P1 §3 与算法1、P2 §4.1，以及完整 A。

**判断：充分。** `X=(h,g,C,ξ)` 冻结于槽起点；U 为下一槽决策，当前 R 来自旧 C；非终止时下一快照含 `C'=U`，故 `R_n+γ^n Q(X',π(X'))` 的时域匹配。新 U 的物理作用延迟一槽，由后继 C 传递价值。正常一步不等待未来成败才确定样本。文档正确区分此项目推导与 SmoothRL 原始 2n 目标，也承认状态充分性只是实际近似。

**反例核对：**t=100、n=6 时，将 100–105 的 R 配帧112的 next state 会跳过一决策；A 例1明确拒绝。只给 E 加 mask、却把新 proposal 的前6项当 C，同样不成立；A §1、§4已排除。**必要修改：无。**

### Q5：真实 request 与纯建议的边界，是否因未激活 terminal 样本而被破坏？

**位置：**D §8.2–8.3；A §2.2–2.3、§5.1、§9 例4；I §5.1、§5.3、T11/T15。**已读证据：**全部冻结事件与终局规则；基于其固定输入／随机性前提独立核对队列决策定义。

**判断：充分。** request 事前被实际运行时接纳并绑定冻结 X、权重、随机性、目标与未来槽，结果来自同一在途计算。普通样本还需真实 commit 和 next queue；当前 C 已真终止时，无需虚构提交／物理激活，原结果可构成 terminal delayed-decision 样本。未入该控制流程的 shadow 建议只保留监督资格。

**反例核对：**Harness 同时建议 A、B，只有 A 的实际请求被接纳；任务终止不能让 B 事后获得 transition。若计算取消、U 不可追溯，也不能用新观察补算。A §5.1、例4与 I T15 均覆盖。**必要修改：无。**

### Q6：terminal actor 是否仍偷偷按未来存活筛选？

**位置：**D §8.3 第235行；A §5.1、§9 例3、§12；I T50；E §2.4；调研 §1。**已读证据：**冻结终局文本与 S3 §6；下述为本次独立代数核对，不归于上游论文实测。

**判断：充分。** 主方案采所有合格事前非终止 X，包括 C 随后提前终止的行；critic terminal 不 bootstrap；actor 重算 π(X)，无未来 terminal 输入，Q 梯度仍只经 E。文档也明确近似 Q 可能在必然终止处产生虚假梯度，且只主张相对于声明 replay 分布的目标。

**反例核对：**在相同采样频率下，两个状态存活概率为1与0.2、条件存活梯度相同，已平均终局的 Q 梯度比为1:0.2；再按实际存活筛 actor 后变为1:0.04。该二次加权已被主方案删除，旧 mask 仅列为改变目标权重的消融。无需因近似 Q 风险重新引入该 mask 或额外 terminal-only 网络。**必要修改：无。**

### Q7：终局回报传播、任务终止与外部截断是否会混淆？

**位置：**D §7、§8.3；A §5.2–5.3、§7、§9 例3；I §5.3、T11/T12/T21。**已读证据：**A 的回报定义及请求规则；P1 的时间跨度比对；本次手算核对。

**判断：充分。** 真终止 L 步 target 为实际折扣回报，无 bootstrap；前驱维持自身一步 target，奖励经统一 Bellman 链传播。终局证据时刻、评分返回时刻、已发生 commit 各自保留；迟到标签不覆盖控制事实。先接管／超时、后成功不能倒追为正常 terminal。

**反例核对：**γ=0.9、n=6，下一槽第三步得1，下一槽 target=0.9²，前驱在价值学到后为0.9⁸，与 A 例3一致。若成功分支直接回填1、其他分支仍用无条件0.5，等概率期望会被抬至0.75；A §5.2已禁止此混合。服务断线、主动接管也没有被写成吸收失败。**必要修改：无。**

### Q8：接管隔离是否仍遗漏介入删失？

**位置：**D §8.3、§9、§10.3；A §6.2、§12；I T35/T51；E §2.4、§3.3。**已读证据：**冻结接管规则与 S3 §5，独立检查前驱与断裂槽时间关系。

**判断：充分。** 正常前驱有真实 next snapshot 时保留；被打断槽隔离；边界本身不明才连带隔离依赖前驱。事实仍保存，接管不自动负奖。文档明确这种处理维护转移真实性，却不消除选择偏差，要求按 goal／错误类型／原因／版本看准入与自主复尝试覆盖。

**反例核对：**同可见 X 下，A 的隐藏分支各半得+1/−1，坏分支总先被接管；B恒为0.2。只保留 A 的好分支可让 Q 错选 A。A §12已明确该例，零支持也不靠重加权恢复。剩余可识别性与数据密度是实验门槛，不是要求首版新增风险 critic 的理由。**必要修改：无。**

### Q9：BC 标签是否真来自同一可部署信息集？

**位置：**D §6.3、§6.6、§10.2；A §4.2–4.3、§8；I §4.5、§5.4、CorrectionLabel、T32/T53。**已读证据：**P2、DIDA 摘要边界、冻结标签契约。

**反例核对：**100时刻图像相同，107时刻物体分别向左／右滑，老师看到后续反馈分别向相反方向纠正。这不能成为100时刻的普通确定标签；当前记录和分流会识别。DIDA 可研究无延迟教师标签，不意味着 GPT 本身已是可靠教师。**必要修改：无。**
