## 逐问审核

### Q1 请求尚未物理生效，能否作为真实队列动作？

定位：01 §8.1–8.3；异步附录 §2–3；03 §2.4。依据：S1、S2。反例：只保存帧100预测的20个数，把前6个当旧承诺，或把 next state 取到112而奖励只累积到105，会把不相符区间拼接。另一个极端是见 U 未激活就删除已经真实提交的决策，遗漏队列后果。

充分性：正文明确 X 含真实 C、U 对应下一槽，正常转移满足 `X_next.C=U`，请求、commit、activation 各有证据；n 与 γ 的单位也明确。仅影子建议没有这种转移。一槽目标与 SmoothRL 的2n目标已区分，前驱不依未来成功改 target。**本题通过，无必要修订。** 实施时仍须执行三阶段与索引回放验收。

### Q2 终局例外会不会把超时或接管后的成功洗成合法 TD？

定位：01 §8.3；异步附录 §5.1–5.3、§7；03 §2.3–2.4。依据：S2 的并发时间定义及本项目事件推导。反例：第4步已被 Harness 改写，第5步才稳定完成，即使原推理随后返回，也不能认定旧 C 合法地产生该终局。相反，若第3步已经满足完整终局证据，计算第8步返回，则“撤销执行权限”不必销毁原冻结计算结果。

充分性：附录235行按事件顺序裁定，稳定性证据不足时不得回溯；233行区分事件时间与核验返回时间，真实 commit 不被改写。terminal 仅配同一事前请求的真实 U；缺 U 保留事实，不补动作；外部截断不置零价值。**本题通过，无必要修订。** 边界同时发生或时钟证据不足时保留 pending／隔离，已有契约足以容纳。

### Q3 终局行不参与 actor，会不会再乘一次存活概率？

定位：异步附录 §5.1、§12；接口 T50；01 §8.3；03 §2.4。依据：S1式(2)的状态期望与本次概率推导。反例：等频的两类 X，存活率为1和0.2，存活后动作梯度均为1。正确 Q 已包含存活率，梯度比为1:0.2；若又仅从存活行抽 actor，变成1:0.04。

充分性：首版从合格事前非终止 X 抽样，保留后来终局但 U 未激活的行；不用未来终局作在线输入。必然终止处理想 Q 应对 U 平坦，近似 Q 假梯度列入解析验收；所称目标仅相对 replay 状态分布，并未声称真实占用分布无偏。**本题通过，无必要修订。** 这不免除超时和介入删失，正文已作区别。

### Q4 保留合法前驱是否等于消除接管选择偏差？

定位：01 §8.3、§9、§10.3；异步附录 §6.2、§12；03 §3.3。依据：S2 的相邻转移定义与条件采样推导。反例：动作A的隐藏结果各半为+1/−1，B恒为0.2；Harness只截走A的坏分支，剩余数据会错误偏爱A。删除整回合会丢掉合法前驱；保留前驱也不能凭空补回缺失后继价值。

充分性：文本允许准确边界的前驱继续一步 bootstrap，边界本身不明才连前驱隔离；不把接管作 done或统一负奖。T51与独立复尝试要求按方向、原因、Harness版本检查覆盖，明确零覆盖不能靠重加权恢复。**本题通过，无必要修订。** 数据密度不足或无辅助表现未改善时应留在相应阶段诊断，这已写入路线门槛。

### Q5 未执行纠正、未来反馈和 flow 部分标签如何分流？

定位：01 §6.2–6.3、§9；异步附录 §4.2–4.3；接口 §5.4/T14；03 §2.4。依据：S3–S5。反例：标签只覆盖夹爪一步，却复制成6步；或者未知末端标签填零，仅在末端 loss mask，仍经 noisy-action token 改变有效标签的预测。帧107见滑落后形成的路径也不能倒填成帧100已选动作。

充分性：纯建议长期保留为监督候选但不伪造转移；标签绑定冻结快照与依赖观察，后验信息另作特权视图。首版允许完整可信窗口，部分窗口须验证输入、注意力、目标与推理的一致处理，否则暂不进入该分支。DIDA被用于说明扩展可能性，没有声称其专家前提在本工位成立。**本题通过，无必要修订。** 这些明确待测的学习边界不应被误判为已实现，也不应仅因尚未编码而否决。

### Q6 goal 只进入 VLA 提示，能否称共享双向学习？

定位：01 §5、§10.2、§10.4；异步附录 §12；接口 §5.2/T17；03 §2.2。依据：S6、S7及目标条件价值定义。反例：物体已在B，goal=B应终止，goal=A应抓取；若 editor、Q或筛选器丢失goal，即使底模读不同语言，也会混合两种价值。表征升级而 predictor 维度不变，也不能证明语义兼容。

充分性：规范goal贯穿actor/Q/target，原生路线还覆盖V，扩展检查base、editor、候选筛选、predictor及C/有效时刻。正文要求计算图和小样本条件化行为检查，而非仅维度通过；换向切episode、清旧队列，同包双向发布。**本题通过，无必要修订。** 上游单任务模块缺goal不被误称原实现错误，但不能不改造用于本项目。

### Q7 少示范、零成功时，路线选择与部署产物是否说清？

定位：01 §1、§9–11；02 §4/§12；接口 §6.1；03 §1.2、§2.1、§2.5。依据：S6–S8。反例：训练集平均L2很低却从不闭夹爪；候选存在但Q总选错；将EXPO的N改为1却称只减采样数；只导出VLA权重而省略部署必需的编辑器、筛选Q或normalizer。

充分性：先检查可信纠正可学性，再区分候选出现、编辑可达、Q选中、独立闭环迁移；有限采样未找到不等于支持为零。原生、编辑、完整头都有预检与可改选条件，不要求先长训新头。完整部署包计入全部必要模块，并做同输入、目标、C和噪声的输出一致性检查；复合policy进步不冒称底模独自吸收能力。**本题通过，无必要修订。** RAPolicy队列改造未完成、hold对照未满足连续执行要求均已明示。

### Q8 H1 是否真正隔离 RL 的额外收益？

定位：01 §13.1/§13.4；03 §3.1 H1、阶段B。依据：S3 的动态聚合机制及实验归因推理。反例：RL组持续收纠正，BC组仅固定SFT；或RL组多了状态估计与新动作头，把总差异全部归给RL。

充分性：两组同起点、示范、纠正规则、资源上限，均各自在线采样；头或信息不同须另列消融。不虚称轨迹相同或同时严格匹配全部预算。共同留出起态、无动作辅助的双向差值和区间为主，实际成本并列；区间过宽定为证据不足。**本题通过，无必要修订。** H1门槛由实验前任务需求填写，当前不编成功率是合理边界。

### Q9 H2/H3 是否把系统收益误认成参数学习？

定位：01 §13.2–13.3；03 §3.1 H2/H3、阶段C/D。依据：S3及析因／分叉训练的因果推理。反例：循环后起态更容易，被误称共享迁移；仅测新旧policy×新旧Harness四组合，就声称程序扩展改善了训练；新增程序替policy完成困难步骤，却把辅助成功当学会。

充分性：H2用循环方式×参数共享四组，固定一轴比较另一轴，分开机器人时间与匹配交互量，共同留出起态且不跨无重叠支持外推；还明确四组不足以证明“反向数据改善正向”。H3从同初始policy分叉固定库／扩展库，关闭辅助测试，程序生成与失败成本计入；运行四组合仅用于诊断，标签和练习机会的细归因需补消融。**本题通过，无必要修订。**
