# Harness 作为纠正教师：DAgger、干预反馈 RL 与自动恢复的进一步调研

> **阶段性调研记录。最终联合选择以 [完整方案](../01_RL_Harness真机自主学习技术方案.md) 为准。后续 buffer 源码审计已修正 EXPO 必须频繁完整成功的限制：可信教师动作可经独立监督入口利用；部分 flow chunk 则仍需输入、噪声、注意力与损失的联合适配。**

日期：2026-09-22。限定松灵单臂抓放、VLA 学生、少量初始示范/SFT、基础成功率偏低且包括零；希望减少持续人工接管。以下依据原始论文、项目与公开源码；没有运行训练或真机。论文证据、源码开放范围与本项目推论分别说明。

## 1. 本轮修正：Harness 应当进入学习循环，而不只是提供复位与奖励

**用户提出的“Harness 可以作为 DAgger 纠正教师”成立，且应该提升为首个完整方案，而不仅是附属对照。** 只把 Harness 描述成恢复场景、评分和运行编排，会漏掉它最有价值的一条路径：在学生真实到达的困难状态下，提供更好的动作/动作片段，聚合到训练集，更新 VLA，再收集新一轮失败。

这与固定数据 SFT 有本质差别：优化器仍可使用 VLA 原生监督损失，但数据分布随学生变化，教师在学生实际犯错的状态提供纠正。其主要收益就是减少部署分布与训练分布之间的偏差，不必先等待完整成功轨迹，也不必先建立可靠 Q。

因此，本轮调整首版优先级：

1. **自动门控纠正聚合 + VLA 原生 SFT**：先验证 Harness 能够持续供给有效纠正，以及学生能学会这些纠正。可称“DAgger 式自学习”；若只在接管时收集标签，应明确属于稀疏接管变体。
2. **在同一 Harness 下比较任务奖励 off-policy RL**：完整可信成功供给丰富时 EXPO-FT 更自然；局部有效纠正为主、需重学完整动作映射时继续评估 ConRFT。
3. **动作教师不够好、但坏行为检测可靠时，增加 RLIF 式干预反馈分支**；不是默认取代真实任务成功奖励。
4. 混合经验变丰富后，再比较 STEAM/CFGRL 的局部质量利用。

这不是证明 DAgger 必然优于 RL，而是将最终系统的教师能力纳入算法选择。**有效自动教师存在时，强行先建立在线 actor-critic 可能是不必要的首轮成本。**

## 2. 首先纠正两个经常混用的概念

### DAgger 的教师不必等于执行控制器

标准 DAgger 在当前采集策略访问的状态上查询专家动作，聚合这些状态—动作标签。教师标签可以在“影子模式”提供，而不实际控制机器人；只要标签本身可信，就可以用于监督学习。执行轨迹可以来自学生，或由递减比例的师生混合策略产生。[原论文算法 3.1](https://proceedings.mlr.press/v15/ross11a/ross11a.pdf)

因此：

- **SFT/DAgger 标签**可以是未执行的专家动作建议，要求观测匹配且教师质量可信；
- **真实 RL transition**必须记录实际执行动作及其真实后果，未执行的教师建议不能冒充对应的物理转移；
- **实际接管**会产生纠正轨迹及其后果，同时改变后续访问状态，更接近 HG-DAgger 式采集；
- 如果只记录学生成功轨迹重训，是自训练/成功回流，并不自动拥有 DAgger 在学生失败状态上的专家标注机制。

“未执行计划不能写入真实 replay”正确，但不能进一步推出“所有未执行教师动作都不能成为监督标签”。二者需要不同数据类型。

### 不完美教师有两种不同问题

一是教师**给出的动作不够好**；二是教师**判断何时介入不够准**。前者影响模仿目标，后者影响数据覆盖及干预奖励。两者不能用一个“teacher confidence”笼统解决。

DAgger 不要求教师绝对最优才能运行；但其模仿目标继承教师行为，原理论不能保证纠正一个任意错误教师。RLIF 放宽了动作质量要求，却把重要假设转移到“干预时机与策略次优程度相关”。所有方法都无法从持续错误而自信的反馈中无条件自我纠正。

## 3. 六组原始工作深读

### 3.1 DAgger：学习器访问分布上的教师标签

**证据与身份。** CMU 的 Ross、Gordon、Bagnell；AISTATS 2011 正式论文。原算法包含师生混合采集、对访问状态查询教师标签、跨轮聚合、监督更新和验证选择。原实验不是本项目这种 VLA 真机抓放，不能把理论保证直接解释为真机无人收敛。[正式发表页](https://proceedings.mlr.press/v15/ross11a.html)

**开放与可用性。** 算法描述公开；本轮未核验原作者提供的 VLA/真机实现或许可证。这里借鉴算法与数据契约，使用现有 VLA SFT 管线实现，不把第三方同名仓库当作者官方复现。

**对 Harness 的关键启发。**

- 教师可由代码技能、几何规划/MPC、较强 VLA、或这些模块组合承担；不要求其与学生同架构。
- 先保留实际失败状态和学生当时的候选动作，再让教师给建议，不能只重复采整齐初始场景下的教师轨迹。
- 低基础成功率不是理论上的统一门槛；教师能否对学生访问状态给出可学标签，才是主要依赖。
- 多轮持续保留初始示范与历史纠正，防止新一轮只学最近错误，遗忘已有能力。

**边界。** 全访问状态标注可能昂贵；真机也很难让人对学生轨迹逐帧影子标注。自动教师若足够便宜，可提供更密标签，但仍需控制错误标签与近重复数据数量。

### 3.2 HG-DAgger 与 IWR：稀疏接管不等于全状态 DAgger

**HG-DAgger。** Stanford 团队；ICRA 2019，原实验是仿真与真实自动驾驶。由人决定控制权切换，接管时提供动作，避免人一边看学生执行、一边标注而产生的时延/操控错觉；其不确定性风险阈值并不等于已经实现全自动教师。[原论文](https://arxiv.org/pdf/1810.02890)

**IWR。** Stanford 的 Mandlekar 等，2020 年预印本《Human-in-the-Loop Imitation Learning using Remote Teleoperation》。接管与非接管数据分池、训练时等比例采样，用接管强化困难阶段，也用学生动作约束训练变化。[论文](https://arxiv.org/pdf/2012.06733)、[项目](https://sites.google.com/stanford.edu/iwr)

**重要证据纠错：IWR 这篇论文实验是仿真，不是真机。** 论文 §IV-A 明确由于 COVID 无法访问机械臂；§V 使用 MuJoCo/robosuite Sawyer 和物体状态输入。项目视频与“6-DoF manipulation”描述不能替代正文条件。本轮未找到该论文明确的官方完整代码及许可，标未知。

**对本项目的判断。**

- 将 human gate 换成 Harness gate，且只在接管片段提供动作监督，宜称 **自动门控的稀疏纠正聚合**，不能冒称原始全状态 DAgger。
- IWR 的平衡采样思想值得优先实现，避免纠正被大量普通动作稀释；但“所有学生动作也做 BC”在弱策略条件下可能固化错误。
- 首版应比较“初始示范 + 可信纠正”与“再加入经过筛选的学生动作”两种采样，不能预设 1:1 是松灵弱 VLA 的最佳比例。
- VLA 原生 flow/diffusion 监督损失可继续使用，新增的是来源/质量分池、采样与有效动作 mask，不要求替换整个策略结构。

### 3.3 ThriftyDAgger：决定何时找教师，不能替代教师本身

**证据与身份。** Berkeley 团队；CoRL 2021 工作、PMLR 2022 出版。门控结合新颖性和任务风险，并按教师介入预算调节，评估含仿真与真实 da Vinci 线缆操作。[正式论文](https://proceedings.mlr.press/v164/hoque22a/hoque22a.pdf)

**开放边界。** 官方仓库提供算法、robosuite 示例和 HG-DAgger/LazyDAgger 对照；README 明确真机实验接口代码需要联系作者，不能说公开仓库已含完整真机部署。根许可证本轮未核实。[官方仓库](https://github.com/ryanhoque/thriftydagger)

**对 Harness 的用法。** 把“持续风险/新颖性 + 预算 + 退出条件”用作自动 teacher 调用器。预算可从人的分钟数改为机器人额外占用、LLM token、较慢规划器耗时，属于本项目扩展。

**具体兼容边界。**

- 风险估计要有本任务标签/成功定义，不能直接拿 VLA token 熵当任务失败概率。
- 进入与退出阈值应有迟滞，避免 learner/teacher 快速反复切换。
- 触发过迟会落到教师也无法恢复的状态；触发过早则学生几乎不探索、数据主要变成教师常规轨迹。
- 该方案只优化“何时介入”，没有自动生成更好动作，也不直接解决复位。

### 3.4 RLIF：从“需要干预”学习，而不必照抄教师动作

**证据与身份。** UC Berkeley；ICLR 2024。对导致干预的前一条转移给负奖励，未干预为零，聚合全部交互，使用 RLPD 进行 off-policy 学习。真机为 Franka FR3 插入与布料展开，视觉 EfficientNet-B3，并非 VLA；附录使用 5 条次优轨迹初始化，10 Hz 控制，人用 3D mouse 干预。[论文算法 2 与附录 A.2](https://arxiv.org/html/2311.12996v2)、[正式会议信息](https://rlif-page.github.io/)

**开放边界。** 作者仓库为 JAX/Flax，README 公开的是 D4RL 仿真 value-based/random intervention 入口和 DAgger 对照；未在公开入口核实完整 FR3 真机管线，根目录未显示明确 LICENSE。应记“研究代码公开、真机与许可待核”，不能称开箱即用 VLA 方案。[官方仓库](https://github.com/pd-perry/RLIF)

**为何会改变选型。** 自动教师可能擅长发现错误，却给不出最优动作。此时强 BC 会继承教师粗糙修正，RLIF 提供另一条学习信号：减少导致任务纠正的行为。这比无差别把所有自动接管当专家更合理。

**不应直接作为首选的原因。**

- 我们的简单抓放通常可以定义独立终局完成判据；没有必要先抛弃它，只优化“不被干预”。
- Harness 若只在碰撞风险时介入，学生静止不动也可能不触发，干预最少不等于任务完成最多。
- reset、网络迟延、教师轮换、预算耗尽、相机故障造成的接管，不能统一解释为上一步任务动作差。
- 若 gate 由正在训练的同一个 Q 决定，RL 再把这个 gate 当奖励，可能形成自我强化偏差；至少冻结评价窗口、使用独立证据并记录版本。
- 迁移到 VLA 需要选可训练动作头或原生 VLA off-policy 更新器，不能仅把 ResNet 换成 VLA 名字。

建议是把 RLIF 式事件反馈做成**可关掉的辅助信号/独立对照**：保留真实 task success，分离 task-correction、安全中止、行政暂停、reset 等事件；奖励归因到确实导致纠正的学生动作窗口。与 ConRFT/EXPO 组合后已是新的奖励配方，不是原 RLIF 复现。

### 3.5 UniIntervene：真正将自动检测与可执行纠正接入真机 RL

NTU/北京邮电大学；2026 年论文，项目/仓库标 CoRL 2026。未来条件价值估计发现无进展，检索过去干预中的高价值目标，再用 goal-conditioned 恢复策略执行纠正；论文将恢复转移写入 RL replay。UR7e 实验的学生是 HIL-SERL 系，π0.5 为 SFT 对照，不能称原生 π0.5 在线 RL。[论文](https://arxiv.org/html/2606.12372v1)

它是本轮最直接支持“自动教师不只是 reward/reset”这一系统角色的真机证据。但已有审计明确：MIT 仓库只发布离线训练 pipeline，不含机器人部署/HIL-SERL 集成，也不带训练轨迹、checkpoint 和记忆库。[固定代码与 README](https://github.com/Denghaoyuan123/UniIntervene/tree/40f461f97573383c9cc8fdba43df56f9eb5bbea1)

**排序调整。** 应把它从“以后可能有用的恢复附件”提升为 **自动教师架构的主要参考候选**。但不能直接把它升为本项目首个必须部署模块：它需要过去成功、失败与干预经验，且模型/数据/线上集成成本较高。

更可行的逐级路径是：先由可验证的代码/MPC/已有 VLA 产生纠正与记录，再蒸馏常见纠正、训练触发器和恢复记忆；只有重复失败复杂到简单原语不足时，才承担 UniIntervene 整体学习成本。这个路径是本项目建议，尚无现成“松灵 + UniIntervene + VLA DAgger”公开复现。

### 3.6 PARTS：2026-09 的直接融合例子，但还不是自动 DAgger 教师

UT Austin、UC Berkeley、Autel US 作者；2026-09-18 预印本。编码 Agent 依据人工任务契约生成 selector/verifier/reset 程序，在 YAM 与 Franka 真机上为目标子任务运行局部 TD3+BC；冻结 VLA，学习受限维度的有界 residual，并做成功重加权重训。[原论文](https://arxiv.org/html/2609.21788v1)

**边界必须保留。** 人指定瓶颈、动作维度与范围并审核程序；不确定成功判断可请求人工标签，无法自动复位时仍由人执行。它主要面向大部分阶段可执行、少数阶段不可靠的任务。代码程序负责选择、检测与复位安排，并不提供通用专家纠正动作；真正的新动作来自局部 RL。

**开放性。** 论文给出作者项目地址，但本轮访问该站与候选仓库未成功，未核验可运行训练代码或许可证。访问失败不是未开源证明，状态应记“尚未核验”。[作者项目链接](https://destiny000621.github.io/PARTS/)

**取舍。** 比已有列表更直接研究 Harness + RL 的整体融合，值得纳入架构对照；但固定基座附近残差及人工契约仍在，未改变本项目“完整动作纠正 + 可更新 VLA”为默认方向。若后续发现基础策略已经能完成主体流程、只在夹爪闭合/放置微调等局部卡住，则 PARTS 机制可能比重学全任务更合适。这个选择依据失败结构，不依据跨论文起始成功率数字。

## 4. 不完美 teacher 的进一步补强：SiLRI 有价值，但没有现成 VLA 闭环

SiLRI 用干预分布的不确定性和状态相关拉格朗日系数调节模仿约束，论文明确使用较简单视觉模型，将 VLA 纳入后续工作。其公开 PyTorch HIL-RL 工程提供 SiLRI/HIL-SERL/HG-DAgger/GAINS 等路径，已有审计核为 Apache-2.0。[原论文](https://arxiv.org/html/2512.24288v1)、[官方代码](https://github.com/nuomizai/HIL-RL)

相比固定 BC 权重，它更适合“有些状态教师很好、有些状态教师较差”的问题，值得作为 ConRFT 质量适配的机制对照。不过，教师稳定输出错误动作时，动作方差可以很小，**一致性不能替代正确性**；把人换成确定性脚本后尤其明显。其 VLA 适配仍需新增，因此本轮没有证据使它无条件取代 ConRFT/EXPO。

### 补充：ASkDAgger 更适合 Harness 的技能/参数层

TU Delft / RWTH Aachen，TMLR 2025，项目公开代码、数据与 Colab 入口。SAG 调节查询门槛，FIER 让教师验证或重标学生计划，PIER 按不确定性、成功与数据年龄调整回放；真机包括 Franka 装配与 Spot 内置技能分拣。[官方项目](https://askdagger.github.io/)

它应列为 **Harness 技能调用/参数纠正的优先基线**：Agent 可以审核“选哪个物体、用哪个 skill、抓放位置参数”，比逐帧连续动作监督更接近语言模型擅长的层次。不过，作者明确定位为中高层控制，依赖已有可参数化 primitive；Franka 装配使用固定抓放高度与二维位置参数。它没有证明低层 VLA 从弱策略学会完整抓取。若希望同时改进 VLA，仍须把技能执行展开为低层轨迹，再建立前述 DAgger/SFT 通路。本轮只核到项目的代码/数据入口，具体仓库许可证和真机包覆盖未进一步审计。


## 5. 建议实现的 Harness 教师，不止一个恢复函数

| 模块 | 输出 | 用于什么学习 | 第一版实现与限制 |
|---|---|---|---|
| 状态/阶段识别 | 物体位置、是否持物、目标达成、观测可信度 | 任务条件和后置验证 | 感知+几何判据，遮挡/冲突允许 unknown |
| 干预 gate | 接管原因、触发时间、预期纠正目标 | 选择查询状态；可选 RLIF 反馈 | 基于无进展/失败证据，风险与任务纠正分开；不要仅凭文本“我觉得失败” |
| Action teacher | 当前状态的建议动作或可执行纠正片段 | DAgger/SFT 标签；执行后可供 RL | 代码原语、MPC、较强 VLA 可组合；包含置信与适用前提 |
| 执行/回交 | 真正执行动作、结果、返回 learner 的时刻 | 真实 replay、局部纠正池 | 清空旧 chunk；坐标/频率/归一化一致；回交需要明确前提 |
| 质量核验 | 局部改进、终局成功、失败/未知 | 标签接受、采样权重、RL reward | 保留与教师独立的物理证据，不因来源是 Harness 就判 expert |
| 聚合与发布 | 初始示范、可信纠正、可选学生样本、版本 | VLA 原生 SFT/可选 RL | 按版本批次更新，先离线验证再回机器人 |

### teacher 与 student 必须共享可学语义

教师可以有更多计算或规划能力，不必架构相同；但建议动作必须落在学生可执行的动作空间。教师若依赖学生看不到的关键状态，应给学生补足观测/历史，或只训练在现有观测下可区分的子任务；否则同样的输入可能对应互相矛盾的监督。

以 code skill 的 `pick(object)` 直接作为低层 VLA 动作标签不成立。要么记录内部控制与对应相机/本体观测，要么明确训练的是高层技能调用策略。坐标变换、绝对/增量动作和夹爪定义的兼容性优先于算法名。

### chunk 标签和 RL 转移需要分开

- shadow teacher 在时刻 t 只给一个可靠动作，就只监督该有效位置；不能复制填满 H 步作为真实纠正。
- 若教师能输出完整可执行 chunk，可将其作为 chunk 教师标签，但需保留教师上下文、目标和信任依据。
- 实际接管形成的 chunk 按真正执行序列记录；中间中断要裁掉未执行尾部或加 mask。
- RLIF 的负信号针对引发干预的学生动作；不能把救援后的动作误当被惩罚对象。
- 窗口内正向/反向目标改变必须切分；标准正向 DAgger 池不得混进未标目标的回收动作。

## 6. 公平实验应增加真正的交互模仿基线

原先“RL vs SFT”的表述容易失真。最低限度分成：

| 实验 | 是否随学生采集新纠正 | 学习信号 |
|---|---|---|
| 固定初始策略 + Harness | 采集但不更新模型 | 测代码/接管本身收益 |
| 静态初始 SFT | 否 | 初始示范 |
| **Harness 门控纠正聚合** | **是** | 初始示范 + 可信局部教师标签，VLA 原生监督损失 |
| Harness + task-reward off-policy RL | 是 | 同等教师/机器人预算，真实 reward 和回放，必要 BC |
| 可选 RLIF/质量适配分支 | 是 | 清晰归因的干预反馈或状态相关监督权重 |

如果只能负担三个实验，保留固定策略 + Harness、交互纠正聚合、所选 RL；不要只让 RL 拿到新增纠正，而把 SFT 限制在最初示范后宣称 RL 优越。

在相同初始状态分布、人工/teacher 调用预算、机器人时间和计算预算下比较，并单列 learner 无接管成功率、系统辅助成功率、教师纠正成功率、有效纠正接受率、接管与复位耗时、未知/误判比例。先同数据池比较优化，再匹配在线采集预算；二者回答的问题不同。

## 7. 明确改变与不改变的判断

**改变：** 首版系统主路线应从“先选 ConRFT/EXPO，再补 Harness”调整为“先构成可训练的自动纠正闭环，并以 DAgger 式 VLA 更新跑通；再选择 RL 增强”。这是一条完整自学习方案，并非仅把 SFT 当保守占位项。

**改变：** UniIntervene 上升为自动教师的重要架构参考；ThriftyDAgger 提供接管预算与门控；RLIF 提供不照抄次优教师的额外学习路径；PARTS 提供真正的 Agent 程序与局部 RL 融合证据。

**不改变：** 没有发现可核验、已经公开完成“松灵弱 VLA + 自动教师 + 少量初始示范 + 长期无人工复位”的现成训练栈。新增论文不应消除动作、观测、奖励、数据与版本融合的硬门槛。可靠教师能否被构建仍需验证，但它可以先通过局部纠正、影子标签和代码技能逐步形成，不必要求启动前已经拥有一个完整任务的高成功率专家。
