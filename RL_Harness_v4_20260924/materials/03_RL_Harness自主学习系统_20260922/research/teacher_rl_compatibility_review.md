# Harness 自动教师、DAgger 与 RL 的兼容性复核

核验日期：2026-09-22。针对松灵 ALOHA 类平台、首任务单臂抓放、少量成功示范/SFT、基础策略成功率偏低（包括零）；不采用 ACT，不假定具体机器人就是 PiPER。本文是设计评估，没有实施训练或真机测试。

**结论：Harness 可以成为 DAgger 式纠正与 RL 的连接层。关键条件是教师产生了与学生所见状态对应的动作监督，且 RL 使用真实执行的动作及其后果。观察员打分、语言建议、恢复复位各自有价值，但不自动等于 DAgger 数据。当前查到的原始工作支持这种组合的各个部分；没有核实到可直接部署于用户机器人、自动教师可靠、复位自主、VLA 学生持续提升的完整现成方案。**

优先实现可审计的“教师建议—受约束控制器执行—环境独立验收—纠正数据聚合—VLA/RL 更新—撤掉教师评测”。GPT6 可以作为待标定的语义教师候选，不能预设它是机器人动作专家。

## 1. 五项直接影响设计的原始依据

### 1.1 DAgger：教师不必是人，但必须提供动作监督

DAgger 在学习者访问的状态上获得专家动作标签，并把新标签不断加入训练集，针对的是部署时状态分布偏移。因此规划器、技能控制器或另一策略可以做教师；只做失败判断、把机器人搬回起点而不训练学生，不能据此称作 DAgger。原始结论依赖专家质量、覆盖与可学习性，不保证任意大模型教师都会使学生进步。[DAgger 原论文，AISTATS 2011](https://proceedings.mlr.press/v15/ross11a.html)

本项目适合称“带自动教师的 DAgger-like 纠正聚合＋off-policy RL”。如果只在触发风险时标注一段数据，应明确是选择性干预，不能把原始 DAgger 全状态标注的条件自动继承过来。

### 1.2 SAGE：最直接的不完美 VLM 教师＋RL 例子，尚非机器人基线

2026 年 9 月，FBK 与都灵大学提出：学生不确定时调用 VLM 并执行其动作；学生动作进入 PPO actor loss，教师动作进入 BC，环境奖励支持 value 学习；单独测试撤掉教师后的学生。实验是离散视觉导航/推理及 ALFWorld，并非连续动作真机 VLA。作者明确承认：初期 critic 不可靠，优势加权 BC 不能保证过滤教师错误，消融也没有显示一致的鲁棒性收益。[SAGE 论文](https://arxiv.org/html/2609.01567v1)

**开源审计反差：**论文称代码可用，但 2026-09-22 官方仓库根目录 API 实际只返回 `LICENSE`；MIT，0 stars/0 forks 快照。属于方法参考，不能按可运行框架评估。[官方仓库](https://github.com/giobin/SAGE)；[根目录 API](https://api.github.com/repos/giobin/SAGE/contents)

对本项目的启发是明确分流 teacher/student 数据，并用环境结果验证教师。连续动作 VLA 的熵不能直接照搬其离散归一化熵门限；低熵也可能是自信地犯错。

### 1.3 IDE：真机语言教师指导 VLA 探索，但教师仍是人

MIT/MIT-IBM 的 IDE 让操作员在执行途中修改语言指令，VLA 继续生成动作；PPO 对干预提示和原始任务提示进行混合更新，奖励仍按原始任务验收。官网有真机低成功、包括起点零成功的实验，代码标为 coming soon。它支持“语言教师可以帮助探索”的方向，未验证自动 VLM 替代操作员或无人复位。[IDE 官方项目与方法说明](https://xinyunsunshine.github.io/ide/index.html)

这里的混合更新是专门设计的学习算法。工程上不能把提示词改成“向上移动”，执行后又无记录地当作原始提示下的普通 on-policy 样本。当前核验依据是官方项目；项目 PDF 链接抓取失败，因此不额外推断其实现细节和许可证。

### 1.4 VLA-Corrector：更贴近机器人 Harness 的截断与重规划组件

浙大/达摩院方法冻结 VLA，使用外部视觉潜变量动力学监控器检测动作块失效，清空旧队列并对下一次生成做 OGG 引导。论文真实 PiPER＋π0.5，9 个任务，每任务每方法 20 次；真机适配每任务 10–30 条遥操作示范。它改善推理闭环，不更新 VLA，也不自动构成 DAgger/RL。论文明确 OGG 受原 VLA 动作能力限制，无法创造骨干模型无法表达的恢复动作。[原论文及附录 E](https://arxiv.org/html/2607.01804)

官方仓库 SHA：`9d23a0ba6fad562d3ed1a68fc52c8a12459abb41`。Apache-2.0；80 stars/6 forks 快照。已公开 LeRobot 分支、监控/引导模块与训练入口；README 明确不含数据、任务 VLA checkpoint 和 corrector checkpoint。主示例是仿真评测，递归文件树未匹配 `piper` 文件名，尚不能确认论文 PiPER 真机执行链已完整公开。[固定版本仓库](https://github.com/ZJU-OmniAI/vla-corrector/tree/9d23a0ba6fad562d3ed1a68fc52c8a12459abb41)

适合列入 Harness 截断器候选，不宜立刻替换 learner。若 VLA 表征跟着 RL 变化，外部监控器依赖的特征分布也会变化：需要冻结单独监控编码器，或成套版本化并重新标定。该兼容性是本项目工程推断，尚未联合实验验证。

### 1.5 ALOE：对混合干预数据的 critic 语义尤其相关

AgiBot 等机构的 ALOE 用 π0.5 actor、Q-chunking、悲观 Q 集成与优势加权 flow matching，处理历史策略/人工纠正混合数据。v2 论文有三项真机任务，初始示范为 50/150/50 条，均人工复位；吞吐指标排除复位时间。官网已扩展到四项任务，不能把官网新数据与 v2 表格混作同一次实验。两者都不是自动教师方案。[ALOE v2 原文](https://arxiv.org/html/2602.12691v2)；[官方项目，代码 coming soon](https://rooshy-yang.github.io/aloe/)

它支持“真实纠正片段可以参与 off-policy VLA 学习”，但代码尚未提供，不能据此替代当前可复现的 ConRFT/其他 learner。尤其不能照抄“介入即失败”：其采集协议对特定风险截断赋失败标签，是任务定义选择，不是所有 Harness 干预的必然含义。

本轮没有把论文机构声誉换算为工程成熟度。上述最新工作引用量未核实；仓库关注度只是日期快照，不能代表真机复现人数。

## 2. 哪些教师信号可以进入哪些学习通道

下表是本项目数据契约建议，依据实际可观测后果推导，不是某篇论文的复现实验结论。“成功池”需要分别记录**系统执行成功**和**纯学生自主成功**。

| 教师输出/执行情况 | Critic / RL transition | BC / DAgger 标签 | 成功池 |
|---|---|---|---|
| 教师动作真实接管执行，含规划器、技能控制器、遥操作 | 可以：存 `o, a_rl, reward, o_next, dt, goal`；`a_rl` 是选定 learner/env 边界真正采纳的命令，不默认是最低层驱动命令。off-policy Q 还需明确学习的目标策略 | 可以：标签应对应当前观测、动作坐标和实际可学习的控制语义；通过质量筛选 | 独立验收整个任务后可进系统成功池，保留接管标记；不能算纯学生成功 |
| 查询教师动作但没有执行，学生继续原动作 | 教师建议不能与学生产生的 `o_next/reward` 拼成真实 TD 样本；学生真实 transition 正常保存 | 可以作为 counterfactual action label，但必须有可信教师和观测对应关系 | 不能凭建议宣称成功 |
| 教师生成完整计划、语言纠正或子目标 | 执行后才有低层 transition；高层 RL 需单独定义 option/subgoal 的状态、持续时间与奖励 | 可以训高层语言/技能选择器；不能直接当低层关节动作 BC。若重标原始任务需算法与语义支持 | 按原始目标验收；子目标成功不冒充整任务成功 |
| 两段轨迹的偏好比较 | 先形成偏好模型/奖励模型或对应 preference objective，不能把“更好”直接当标定环境 reward | 适用于偏好学习；不是动作级专家标签 | 偏好更高不等于成功 |
| 进度/失败概率/连续分数 | 可以作为经校准、版本固定的奖励或 shaping 输入；不能补造动作后果 | 单独不构成 BC/DAgger | 只有满足固定成功契约才进入；进度接近 1 不足够 |
| 只把物体复位，未纠正本任务 | 可为恢复目标的真实轨迹；不能直接归入正向任务奖励。跨目标需显式 goal/终止边界 | 可训练恢复策略；无标签或不更新学生时只是运维支持 | 恢复成功进入恢复池；不是正向成功 |
| 教师模拟/世界模型生成未来轨迹 | 标记 synthetic，只有显式模型式算法才能使用，并评估模型误差；不与真实池无差别混合 | 可以研究性使用，但必须保留来源与权重 | 模拟成功不能计入真机验收 |

需要纠正一个常见误解：DAgger 并不要求每一个教师标签都真正执行；但 **TD 学习所用动作必须与其后继观测是实际因果配对**。所以反事实动作可以是合法的 imitation label，同时完全不是合法的真实 RL transition。

## 3. 动作块、接管与 on/off-policy 的硬门槛

### 3.1 被打断的动作块必须按实际执行切分

假设 VLA 输出 20 步，执行 6 步后教师接管。真实数据是前 6 步学生动作、接管过渡以及随后教师动作；剩余 14 步只保留为 proposed/unexecuted。不能用原 20 步计划配接管后的观测。

宏动作 critic 应使用实际持续长度 `k`：

`y = Σ(i=0..k-1) γ^i r[t+i] + γ^k (1-terminal) Q_target(o[t+k], π_target(o[t+k], goal), goal)`

这要求 learner 支持可变长度/掩码的 chunk，或改为真实短片段/单步训练。若原实现固定 chunk，接入 Harness 前必须核这条适配。中途混合 student/teacher 的块应切开保留 provenance。

动作应区分四层：`proposed_action`（原始建议）、`a_rl`（选定 learner/env 边界真正采纳的命令）、`driver_command`（IK/限速等转换后的驱动命令）、`measured_state`（实测关节与运动）。Critic 使用因果配对且与 actor/deployment 相同动作空间的 `a_rl`，不能一概要求最低层驱动命令。例如 learner 学末端 delta、IK 位于环境内部时，保留实际采纳的末端 delta 作 action，驱动关节命令另存。若改学投影后的空间，actor、critic、数据处理和部署须整体改版。教师接管替换掉未执行学生建议后，记录教师在同层接口被采纳的命令；不能继续沿用学生建议。BC 标签也必须符合部署接口。实测运动是状态/后果，不能倒填成动作标签。详细契约见 [接口与验收附录](../02_接口契约与开发验收.md)。

### 3.2 off-policy 不意味着任意混合都正确

off-policy Q 可以从教师实际 transition 学习，但 next-action target 应与要评估的策略一致。把教师接管后的完整回报回归给学生先前状态，通常得到的是“学生＋教师混合系统”的价值，不直接等于纯学生价值。

PPO 不能将教师动作伪装成由学生旧策略采样，只填入学生 logprob 就做普通 ratio。SAGE 的拆分 loss 是一个参考，但即使遮掉 teacher actor loss，后续 teacher continuation 仍影响 returns 和 state distribution；这不是严格纯学生 on-policy 评估的自动修复。可采用明确设计的混合策略目标、off-policy 修正或分段 bootstrap；最终必须以撤掉教师的真实评测辨别。

### 3.3 干预是删失，不总是失败

“将要滑落时接管”意味着没有观察到学生继续后的结局。应记录 `intervention_reason, censored, env_terminal, time_limit, recovery_goal`。实际越界/碰撞可依据事先约定计失败；监控器不确定、云超时、主动教师课程干预均不能默认等价物理失败。

否则会出现两类偏差：错误惩罚本可成功的学生动作；或者因为总在出错前截断，账面失败率越来越低，但能力没有进步。独立评测应在相同硬件保护下关闭任务教师，固定初始场景分布，保留仍需中止的失败计数。

## 4. 自动教师并不完美：五类不可省略的限制

1. **可学性。**教师若用精确物体位姿/遮挡后状态，而学生只有单帧 RGB，同一学生观测可能得到矛盾动作。先补足历史/相机/状态，或者限制教师只在学生可辨识的情形教学；不能指望更多 BC 自动解决不可观测性。
2. **能力差距。**自动教师必须在相关失败状态分布上比学生更有用。通用语义推理强不等于抓放控制强。先比较固定失败状态集上的救回比例、误触发与额外动作，不用教师自评分排名。
3. **冷启动。**学生零成功且教师也救不回、奖励又稀疏时，没有足够正向信号。用少量经验证示范、成功中间状态起步/可达课程和已验证技能提供支撑；这些都要计入人工/工程成本。
4. **自举错误。**若同一个教师提出动作、打成功标签、训练 reward，再由 reward/Q 筛教师数据，错误会互相确认。保留与训练隔离的几何/传感器及人工抽审真值；教师建议和成功验收不可相互覆盖。模型一致投票也不自动形成独立证据。
5. **过度依赖。**在系统成功池里训练不等于学生已学会。分别统计纯学生成功、系统成功、每任务教师接管时长/次数、人工分钟、物理复位次数以及固定测试集表现；教师查询变少本身不能证明能力提高。

## 5. 推荐的具体组合与升级顺序

以下是尚未联合验证的工程方案，不是新论文声称的完整方法。

**第一阶段：低层教师优先用可执行控制器。**首个抓放任务限定物体/容器、可观测工作区与固定验收；采少量正反向示范。通过经验证的视觉定位＋抓放/撤退技能提供教师执行器。大模型输出 `failure_type / intended_subgoal / skill_id / parameters / evidence / abstain`，由控制器验证参数并执行，不直接把自由文本转换为任意关节命令。

**第二阶段：先收集，再学习。**不修改 learner 算法，先保证 student/teacher/过渡动作可追溯、真实动作块可重放、正反 goal 不串账、独立验收能发现假成功。教师第一次加入应测“额外覆盖了哪些失败状态”，不是只展示整任务成功视频。

**第三阶段：纠正聚合与 RL 各用各的数据。**维护 `D_real`（全部有效真实转移）、`D_teacher_labels`（教师动作及来源）、`D_verified_success`（独立验收及控制来源）。off-policy critic 可复用失败、学生和真实教师转移；actor 用 RL objective 加经质量筛选的 BC/flow-matching 辅助项。BC 权重应可调并可退火；不强制永远贴近最初弱策略，也不把新教师当完美 oracle。确切 loss 依赖选定 learner，不能把不同论文公式直接相加就认为收敛。

**第四阶段：逐步替换教师。**先验证本地几何/技能教师，再验证语言教师能否在失败集上提高有效纠正率。VLA-Corrector 可作为动作块截断组件试验；IDE 提供语言探索的算法启发；SAGE 提供数据分流与撤掉教师评测的启发。三者互补，但不组成已验证的即插即用产品。

**学习器选型暂不因这些新材料翻转。**ConRFT/其他可复现 learner 的动作接口、表征、训练算力与实机适配仍应单独验收；ALOE 和 IDE 当前欠公开代码，SAGE 欠实现且任务域不同。RLinf/verl 等平台提供进程、采样、接管和模型适配能力，也仍不能替代任务 reward、chunk 兼容与真实机器人 teacher 的验证。保持已有学习器比较结论，把本报告作为其 Harness 接口约束。

## 6. 最小记录接口与可验证验收

每个真实执行片段至少记录：

```text
episode_id, transition_id, control_epoch, observation_timestamp
task_contract_hash, goal_id, policy_version, teacher_version
student_proposed_action, teacher_proposed_action, accepted_a_rl, driver_commands
executed_length, execution_ack, controller_source, action_space_version
intervention_reason, censored, env_terminal, time_limit
base_reward, reward_version, independent_success, label_status
teacher_visible_inputs, student_visible_inputs, label_quality
```

反事实标签必须显式 `executed=false`，不制造 `next_observation`。异步教师回复必须匹配当前状态版本、控制 lease 和有效时窗；过期建议只可作离线分析，不能直接用于当前控制。

进入联合学习前，完成四项小规模验收：

- **因果配对审计：**随机抽取接管/截断片段，回放验证每条 `accepted_a_rl` 与驱动执行证据、`o_next` 因果对应，未执行队列不进入 TD；实测运动不能替代所选动作层的标签。
- **教师有效性审计：**固定失败状态集，统计教师实际救回率、错误率与拒答率，失败案例覆盖空抓、滑落、抓错物体、容器遮挡和放置后未松手；独立验收不使用教师自评。
- **学习归因审计：**比较相同人工/实机预算下的 SFT、纯纠正聚合、RL、纠正聚合＋RL；训练结束关闭任务教师，报告 student-only 与 system-assisted 两套成绩。
- **闭环污染审计：**人为注入过期纠正、错误成功标签与 reward 版本切换，确认污染被隔离/撤销，不会自动批准新模型上线。测试与训练初始分布分开，避免课程只挑容易状态造成假进步。

只有教师能在目标状态分布中提供足够有效且可学习的纠正，验收也独立可靠，Harness 才可能持续减少人工。正反循环增加练习机会，但不能免去这些学习条件。
