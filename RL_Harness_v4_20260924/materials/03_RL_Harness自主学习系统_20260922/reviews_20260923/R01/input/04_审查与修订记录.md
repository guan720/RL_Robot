## 2. 没有直接照收的主张，以及修正理由

| 原始主张或早期判断 | 最终判断 | 技术依据 |
|---|---|---|
| RL 真机效率一定比 SFT 高 | 作为实验假说，不作既定事实 | 交互、探索、奖励与复位均有成本；必须与同预算动态纠正模仿比较 |
| SFT 只能利用成功案例 | 不成立 | 失败回合里的正确纠正也可监督；问题是动作标签质量而非回合成败 |
| 正反完整练习等于充分理解 | 不成立 | 可减少复位劳动、可能迁移，但目标与姿态差异也可能造成负迁移 |
| 强大模型生成恢复代码就能替代专家 | 需有可执行原语、感知与独立验证 | 程序编排不能凭空获得物理可达性或缺失状态信息 |
| 恢复成功就意味着能教会学生 | 不成立 | 还需动作同层可表达、学生信息可获得、梯度真正消费数据及无辅助提升 |
| 未执行建议只能作待执行候选 | 过于狭窄，已修正 | 可持久保存并供 actor 的 BC／flow 等辅助目标；DAgger 不要求标签逐条执行 |
| 能进 demo buffer 就能作为原生 RL transition | 不成立 | 历史遥操有真实后果；新查询标签没有。不能配学生后继或填假 reward/done |
| HIL-SERL 有 demo 库，因此原生带 BC | 已纠正 | 已审 SAC／单臂 hybrid actor 为 Q／熵目标，demo 主要通过真实 TD 学价值 |
| EXPO 必须有频繁完整成功才适合 | 对改造后的方案过严，已修正 | base 原生有动作监督机制；独立教师标签路径可绕开默认 success-only，但需拆 batch 耦合 |
| 因为局部标签很多，EXPO 就已适配 | 仍不成立 | 部分 flow chunk 不只涉及 loss mask，还涉及加噪输入、未知尾部与推理一致性 |
| 应直接从零自建轻量 Harness | 改为先预检 Zetta 已有骨架 | 发现已有较完整的候选／监控／恢复／gate 代码；许可和实体缺口仍须过关 |
| 记录“实际动作”就是记录底层关节运动 | 已精确化 | actor/critic 的 action 在声明的 learner/env 边界定义；建议、采纳命令、驱动命令、实测运动分开 |

## 3. 源码核查如何改变选择

主审核版本包括 ConRFT `a779fde7fa5db5a469960a8490c100f35b41b49e`、HIL-SERL `c32939bccb65f3b8c43a9f9add3d322d4ab0264a`、EXPO `803381fc3b4c91a0c47904f1b688fc5e35904f50`、Zetta `1fee179644d52c32fa5a7728751cf0853a29b9c0`、RoboRSI `9b644d270560c440d760965cf1b859df674459de`。固定主仓库不代表已锁定其所有外部依赖；EXPO 的 OpenPI 分支仍需在实施前核准。

最关键的检查是从“数据导入→采样→batch 转换→实际损失”逐段追踪：ConRFT 的 BC 与 TD 默认共用混合 batch；HIL-SERL demo 不意味着 actor 有 BC；EXPO 底层 flow 监督可用动作标签，但顶层转换仍耦合 next 字段。由此，最终选择变为 **优先预检 EXPO＋独立教师标签桥，ConRFT 按动作头需求和实测适配条件备选**，而不是只因 HIL 标签或论文新旧排名。[详细 buffer 核查](research/teacher_buffer_code_audit.md)

Harness 方面，Zetta 已有可审查的执行与版本约束，因此上升为骨架预检对象；它的公开实体后端缺失、执行中取消边界与整体许可待核，也使选择只能是有条件的。RoboRSI 的 RL skeleton 不能被写成已经实现的在线 RL。[Harness 审核](research/autonomous_teacher_harness_survey.md)、[RoboRSI 审核](research/harness_roborsi_audit.md)

## 5. 尚不能由文献替代的实测

- 松灵具体驱动是否支持所需动作边界、可确认停止和时间记录；另一臂如何明确保持。
- 当前感知能否核实抓住、释放、物体身份和下一轮合法起态；假成功是否可控。
- 自动教师在学生失败状态上的覆盖、标签质量及学生的可观察性。
- EXPO 的完整／部分教师 chunk、OpenPI 依赖、batch 改造与推理同步是否可达；若不合适，ConRFT 完整动作头迁移是否更省成本。
- GPU 显存、推理延迟、训练吞吐、日志增长与长时稳定性。
- 同预算下 RL 是否超出动态 DAgger／纠正模仿；撤掉教师后策略是否提高；人工是否真正减少。
- Zetta 可复用代码的许可与实体迁移成本。源码公开不等于可以不核条款直接整库采用。

这些是 P0—P3 的研发输入与验收任务，不通过继续增加论文名称来回避。任何新算法、教师或奖励器都按同一数据与独立评测契约比较。
