# 自主具身 RL 选型调研契约

> 最新选型见[12 低成功率策略再评估与自主练习路线](12_低成功率策略的RL再评估与自主练习路线.md)：ConRFT／EXPO 按实际适配成本竞争；恢复分布与接管数据质量纳入主线，STEAM 用于混合数据阶段。保留 VLA-only、少量示范、单臂首任务；GPU 未确定。本轮为研究评估，未执行真实机器人训练。

## 最新已确认条件（优先级高于旧推荐）

**在线起点的准确口径：基础策略可以经过少量数据 SFT，但成功率仍偏低，包括零成功率，尚未达到当前任务的可用要求。RL 的目标是在尽量减少人工干预的条件下，通过持续学习使其变得可用。既不假定完全没有示范／适配，也不要求先 SFT 到较高成功率才能进入本轮方案。**

不对不同任务的初始成功率设置统一狭窄区间，不据跨论文百分比直接判定方案优劣。如确需数值参考，可将“50% 以下”作为本项目明显未达可用状态的粗略描述；它不是算法准入门槛、跨任务统一标准或最终验收线，也不表示达到 50% 就可用。可用性应按具体任务的自主完成可靠性、失败代价、有效吞吐与人工介入要求定义；同任务、同协议下仍可比较学习前后的改进。

松灵 ALOHA 类双臂，具备遥操作与接管 DAgger；已有模型不代表好策略，当前任务可能极低成功率或未经任务训练。首个任务是 pick-and-place，可以采集少量成功遥操作示范。用户确认只用一条臂完成首任务，另一臂暂不参与；GPU 型号、显存和数量未确定。目标为逐步减少人工复位、接管和值守，未要求冷启动零人工。**保留 VLA（可选 π0.5 等），不考虑 ACT；对整模型更新或保留表征、重学完整动作头无特殊偏好，只按可行性选型。ConRFT 与 EXPO-FT 是首轮候选：已有 π 数据与部署链可用时先预检 EXPO，否则可从官方 ConRFT 验证；不固定认为迁到 Octo 最省工程。UniSteer 先解决发布实现一致性；HIL-SERL 保留为工程参照，详见 12。** [弱策略冷启动审查](07_弱基础策略下的PickPlace选型与冷启动路线.md)保留先验依赖证据，其独立小策略推荐不再作为当前主线。

用户需求（2026-09-22）：详尽调研具身 RL，重点尽量减少人的干预；审核开源、影响力和多方面证据，交由用户筛选。

用户已确认：优先机械臂与移动操作；优先减少真实机器人持续学习中的人工复位、在线接管和现场值守。

## 工作边界

- 公用 `embodied-scientist/` 只读；本轮为专题调研，不进行知识库写入或全域学习资格审查。
- 全部文件保存于本目录；不运行训练、不执行机器人动作，不安装/修改全局软件配置。
- 时间范围：基础方法追溯至早期免复位 RL，重点扫描 2023—2026-09-22；开放领域不声称绝对穷尽。
- 依据原始论文、作者项目页、官方代码与托管平台公开统计；搜索摘要只作线索。

## 必须分开的对象

1. 优化算法：SAC、PPO、离线到在线 RL、残差/小型策略适配等。
2. 自主训练系统：复位、恢复、成功判断、课程与训练调度。
3. 通用执行框架：机器人驱动、异步 actor/learner、数据与版本管理。
4. 自动奖励/任务生成组件：降低部分人力，但不自动构成完整自主 RL。
5. 邻近的自主模仿学习：可以减少人力，但不冒充 RL。

## 人工依赖审核

每个候选分别追踪：初始示范、奖励/成功标注、普通复位、失败恢复、在线接管、设备/装置维护、课程/任务指定、发布评测。将准备阶段和训练运行阶段分开，将作者“autonomous”用语与具体证据分开。

自主运行证据优先顺序：连续运行时长与干预计数 > 明确描述无人值守协议 > 限定演示 > 只有框架主张。未报告人工次数写“未报告”，不等同零次。

## 开源审核

分别核查：RL 更新代码、数据收集、奖励训练/推理、复位/恢复、控制器与硬件接口、评测、配置和版本、权重、数据、许可证、安装与复现说明。Code 按钮、空仓库、第三方重现、基础模型权重不能替代完整方法开源。

开源定性：实现与复现资源较完整 / 核心算法公开但系统缺项 / 仅局部代码或预告 / 未找到官方发布；每项附缺口与原始链接。研究代码阅读不等于在本机复现。
