# 弱初始策略下的 VLA 真机 RL 深查：LWD、ROVE、WCM、TwinRL、VLAC

核验日期：2026-09-22。范围：松灵 ALOHA 类双臂、pick-and-place、可少量遥操作与人工接管、原任务策略可近零成功；不纳入 ACT。只进行文献及公开代码审查，未安装、训练、操作机器人。结论区分原文事实和本项目推断。

## 结论

本轮五项未形成同时优于 ConRFT 的现成替代：LWD 依赖强初始化且保留固定 reference；ROVE 的接管质量处理值得借鉴，但初始数据较多且未核到完整代码；WCM 和 VLAC 的当前公开产物更适合作为评价模块；TwinRL 直接扩展 ConRFT，却增加了数字孪生成本，真机在线部分未完整开放。

**当前更有价值的是补齐 ConRFT 的三个短板：覆盖失败状态的示范、对接管过渡动作进行质量区分、避免单帧价值表征混淆。** 这比为追求“最新”直接换成整个更复杂系统更符合本项目约束。该建议是工程推断，不是上述作者做过的组合实验。

## 1. LWD：真实大规模直接 VLA 学习，但不匹配少示范弱策略

出处：[arXiv v4，2026-09-16修订](https://arxiv.org/html/2605.00416v4)，首次提交2026-05-01；上海创智学院、AGIBOT Finch、Columbia 合作。未在已核原始入口确认正式会议发表。

方法是 DIVL 分布式价值学习与 QAM 策略提取；离线阶段全量微调 actor/critic，在线冻结 π0.5 VLM 骨干、更新原 action expert。更新依据含成功、失败和实际接管转移，是真机离策略经验复用。

但 Algorithm 1 第3步明确设定固定 reference，QAM 改善分布以该 reference 为基础进行价值加权，并未消除先验锚定。附录 B/C：336.6小时成功示范、652.5小时总离线数据；16台双臂在线4小时墙钟对应约60机器人小时。因此不能作为“少量示范近零启动”的证据。

Table I 的0.95混合了短任务二元成功率与长任务子步骤得分，不能改写成八任务完整成功率95%；SFT、离线RL、在线RL的混合均分分别0.76、0.88、0.95。

开放审查：论文两个官方项目地址本次读取失败，定向搜索与论文未定位可核的完整官方训练仓库。状态为“未核实完整开源”，不据页面不可访问断言没有代码。

适用判断：适合已经有较大数据池的多任务车队，作为后续规模化设计参照；不提升到当前主线。

## 2. ROVE：对接管数据的处理比“全部当专家”更合理

出处：[论文](https://arxiv.org/html/2606.17011v1)、[XPENG官方项目](https://xpeng-robotics.github.io/rove/)。2026-06-15；XPENG Robotics、复旦、香港中文大学、上海交大。已核入口为预印本。

它区分自主执行、接管适应、有效恢复，用 TD＋expectile 学状态价值，再以优势条件训练动作。附录G：冻结 Qwen3-VL-4B 骨干、训练 flow DiT 动作头；不是 π0.5 原生 expert，也不是小残差。优势标签来自累积经验，不是到冻结默认动作的 L2。

两项真人形实验分别使用225/220条任务示范，每任务另有180个人类第一视角视频，再采三轮接管交互。迭代成功率45%→80%、56.7%→86.7%，这些数值只描述其自身任务。本项目允许少量 SFT，不能仅因作者起点非零就排除；这里更主要的限制是示范／视频预算、较重训练配置和缺少完整训练仓库。官方项目目前核到论文／演示。

适用判断：**最值得借鉴的是“接管后最初几步并不天然正确”**。松灵主从臂接管虽通常比人形重定向容易，仍可能有对齐、暂停、回撤等过渡动作，应标注并避免无差别高权重模仿。是否需要复杂价值标签方法，先由真实数据质量决定。

## 3. WCM：可公开复用的价值表征模块，不是完整开源 VLA 在线训练栈

出处：[论文](https://arxiv.org/html/2607.29613v1)、[官方仓库](https://github.com/sylvestf/WCM)。2026-07-31；同济、上海创智学院、复旦；已核入口为预印本。

WCM 用历史图像、语言和未来潜状态预测改进价值表征。真机以 OpenVLA-OFT＋AWR、π0.5＋RECAP 为策略优化载体；WidowX-250S七任务，每任务100条SFT示范，8轮、每轮50次rollout。论文“one-shot SFT后RL”属于仿真，不能套到真机。三项 π0.5 抓放由25/50、31/50、34/50至44/50、38/50、43/50。

代码核查：[README](https://raw.githubusercontent.com/sylvestf/WCM/main/README.md) 明确对应RL代码将逐步发布。目前仓库开放价值模型训练、数据转换、测试、可视化，以及真实抓放数据和权重；[training.py](https://raw.githubusercontent.com/sylvestf/WCM/main/world_critic/training.py) 是价值回归＋未来潜状态预测等目标。没有将其误报为已公开完整 RECAP actor/learner。

GitHub API 快照：MIT，82 stars／4 forks，最近push 2026-08-08。这只代表关注度。

适用判断：若初期抓放 critic 把“夹住但未提起”“夹空”“物体被手遮挡”等状态混淆，可先增加有限历史，再测试潜状态预测辅助损失。**WCM 的 state-value 不是 ConRFT action-Q 的即插即用替换**；迁移需保留动作条件，并单独验证。

## 4. TwinRL：直接改进 ConRFT 的覆盖与启动，代价是新建孪生

出处：[论文v3](https://arxiv.org/html/2602.09023v3)、[官方项目](https://twinrl.github.io/)、[官方仓库](https://github.com/zhourui9813/TwinRL)。2026-02首发；北大、清华、港科大、Simplexity Robotics；已核入口为预印本。

Octo＋Franka四项任务，30条真机示范，加60条分布内与30条分布外合成轨迹；孪生在线RL产生初始回放，再按孪生发现的困难场景进行真机接管训练。作者的动机实验显示：示范缺少区域覆盖时，单纯真机探索甚至加接管仍较慢。

这是 ConRFT 风格学习上的数据覆盖扩展，不是通过更强固定动作约束改进。其孪生优先保证视觉/几何与运动学一致性，并非完整接触动力学仿真。“约20分钟”是已完成孪生、数据生成、离线/孪生训练之后的真机在线阶段，不能当成总工程成本。

代码：[ConRFT actor/critic文件](https://raw.githubusercontent.com/zhourui9813/TwinRL/main/serl_launcher/serl_launcher/agents/continuous/conrft_single_octo_cp.py) 可见 replay实际动作的consistency重建＋Q目标。README开放孪生资产、数据、offline训练，但明确真实在线RL仍coming soon。GitHub API：MIT，25 stars／0 forks，最近push 2026-07-11。

适用判断：当前一个抓放任务、允许少量遥操时，优先补采A/B区及恢复状态示范；若后续任务多、场景覆盖成本成为主瓶颈，再投资孪生。这是成本判断，不能据此否定TwinRL方法有效性。

## 5. VLAC：硬件更接近，但不能把“critic开源”当“完整off-policy RL开源”

出处：[2025原论文](https://arxiv.org/html/2509.15937v1)、[官方仓库](https://github.com/InternRobotics/VLAC)、[官方2B权重](https://huggingface.co/InternRobotics/VLAC)、[8B权重](https://huggingface.co/InternRobotics/VLAC-8b)。上海AI Lab。官方仓库标注ICML2026，并链接接受标题《A Generalist Pair-wise Progress Critic Model for Vision-Language-Action Robots》；本次OpenReview全文/API被访问验证阻断，因此不把接受版本与原预印本细节完全等同。

真机是 AGILE PiPER 单臂，2B自回归数字动作actor、8B进展奖励/终止模型；后者名称含critic，但不是PPO用来计算GAE的V网络，另有小value head。算法是PPO＋专家示范NLL，限制相邻策略更新而非冻结初始动作L2。约100条遥操初始化、约30%→90%（作者摘要、200次交互）；不证明零成功率启动，但本项目也允许少量 SFT，不能仅因起点非零排除。应重点比较示范预算、训练实现完整性和自主运行证据。

存在人工难场景重置、引导探索；普通在线数据并非ConRFT式长期Q回放。每点评估10次，独立复现数量未核实。

开源审查：GitHub API快照331 stars／11 forks，代码MIT。仓库树只有模型接口、推理、动作生成示例、数据筛选与视频工具，未找到PPO训练循环；README的训练链接转向InternVL2通用入口。HF模型卡标注CC-BY-NC-SA-4.0，不能把代码MIT扩展成模型同许可。

后续VLAC-Cut有分段筛选、接管调度和经验回流，但主流程是筛选后监督训练，不能换名当新RL优化器。[VLAC-Cut原文](https://arxiv.org/html/2607.09776v1)

适用判断：可作为语言条件进展/成功评价的候选模块，与本地可靠检测做对照。用户当前简单物体A/B搬运不应先用8B评分替代可直接核验的成功条件；评分模型误差可能被RL放大。

## 6. 对本项目可直接执行的研究建议（尚未经实验证实）

1. 保留 ConRFT／HIL-SERL 工程线，先用少量正反成功与失败恢复示范建立可用动作输出；这里“少量”应以状态覆盖为准，不能只追固定条数。
2. 回放保存人类接管开始、同步适应结束、有效恢复、返回自动控制等边界；先人工少量抽查质量，避免错误监督。
3. actor监督可靠动作；critic保留真实失败转移和真实奖励。不能把成功结局全部倒推为前面每个动作都值得模仿。
4. 若策略无进展，分别查初始示范覆盖、奖励真伪、critic过估计、控制接口和动作chunk信用归属，不先笼统归因于算法年份。
5. 在基础系统稳定后再单独加一个模块做消融：优先覆盖/接管质量；历史critic次之；数字孪生、多机器人、巨大通用奖励模型不同时引入。
