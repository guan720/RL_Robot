# 弱基础策略条件下的 RLT、DSRL、PLD 审查

核验：2026-09-22。范围仅限三项方法对初始化的要求；研究审核，未做真机实验。用户有松灵 ALOHA 类双臂、遥操作和接管 DAgger，但当前任务策略可能近零成功、甚至没有任务微调。

## 结论与修正

**应撤回“现阶段无条件首选 π0.5＋RLT”的排序。** RLT 的公开真机证据建立在充分任务示范和微调之后；PLD 更明确依赖非零成功率。DSRL 有无需额外本地任务微调的真机案例，但其起点也具有可用行为。三者都没有证明“本机当前任务几乎不会＋只有稀疏末端奖励”可以稳定、自主地启动正反循环。

低总成功率不等于没有有用技能：若机器人能抓取、搬运，仅最后插入失败，RLT/残差 RL 仍可能合适；若连对象接近与抓取都没有可靠动作，冻结原策略的轻量适配器不宜作为第一步。该区分是本次选型推断，不是已验证的统一阈值。

## RLT：任务微调后的瓶颈优化，降为第二阶段候选

- 原实验使用 π0.6；每任务先采 **1–10 小时遥操作示范**，共同微调 VLA 与 RL token，附录给出 **2,000–10,000 梯度步**。在线才冻结二者、训练小 actor/critic。
- 论文报告螺丝任务 **20%→65%**，属于上述准备后的结果。不能解读为未经任务训练的基础模型从零学会。
- 主要训练先从关键阶段前的部分完成状态开始：完整任务约 **30–120 秒**，关键阶段约 **5–20 秒**；此前抓取、搬运由已经较会做的 VLA 处理。在线 **400–1,000 回合**，作者所述 **15 分钟–5 小时**为有效机器人数据，排除了复位等开销。
- 机制以 VLA 参考动作进行条件化和 BC 正则；参考动作 dropout 允许偏离基础动作，却不构成从零任务能力的证据。

来源：[论文 §IV、§VI、附录 B](https://arxiv.org/html/2604.23073v1)。

RLinf 的 π0.5 实现也明确两阶段：示范上联合 SFT＋token，再冻结做 actor/critic。当前配置为 Franka 插孔与 ManiSkill；因此“有 π0.5 基础权重”还不满足它的整套输入条件。来源：[RLinf RLT 文档](https://rlinf.readthedocs.io/en/latest/rst_source/examples/embodied/rlt.html)。

**建议：** 先用示范/接管获得能稳定进入任务关键阶段的正、反策略，再决定是否用 RLT。无需要求整任务高成功率，但应实测关键状态可达性。

## DSRL：保留有行为基础时的对照，不能推论任意弱策略可用

- 真机单任务 DP：先 **10 条人类示范**，初始 **2/10** 成功；约 **40 回合** RL 后 **9/10**。
- π0-DROID 真机：直接使用公开 checkpoint，实验没有额外本地任务 SFT 步骤；烤面包机 **5/20→18/20**，训练 **80 回合**；勺子放盘 **15/20→19/20**，训练 **65 回合**。前者证明可改善较弱的现成策略，未证明近零任务能力启动。
- ALOHA 双臂结果是**仿真**，基础模型已经在同任务 **50 条示范**上微调 **20,000 步**。LIBERO 目标任务虽未见过，但模型已在同环境 40 项邻近任务、1,693 条示范上微调。
- 原文将可用性归于基础策略仍有任务求解行为；冻结策略的动作生成范围限制探索，未保证任意策略都可被噪声引导到目标行为。

来源：[论文 §5.4–5.6、附录 C.5 与限制](https://arxiv.org/html/2506.15799v1)。

官方代码确有 π0 的 LIBERO、ALOHA 仿真及 Franka 真机入口，真机加载 π0-DROID；未见该仓库提供“松灵双臂从无任务能力冷启动”的完整流程。来源：[官方 README](https://raw.githubusercontent.com/nakamotoo/dsrl_pi0/main/README.md)。

**建议：** 初始评估若可见合理技能片段、偶发成功，可把 DSRL 作为成本较低的比较项；若换噪声后动作仍无法触及关键状态，优先补技能，不继续依靠噪声搜索。

## PLD：适合后续数据回流，不宜当前直接冷启动

- 原文 §5.2 明确利用次优基础策略的**非零成功率**启动探索；不再需要新增 oracle 示范/专家接管，指后续阶段。
- Franka 真机先采 **200 条遥操作轨迹**微调 π0，再训练残差策略；两项任务在 **2 小时内**达到作者所报 100% 成功。此处“无需人类接管”不等于没有初始示范或不用物理复位。
- 后续由策略采成功/恢复数据再 SFT，适合把自主练习反馈到基础模型；这个回流优势不消除第一次成功探索的依赖。

来源：[论文 §4.4、§5.2](https://arxiv.org/html/2511.00091v1)。作者项目页同样将基础 VLA 描述为已能完成大多数步骤、卡在精确反应步骤。[项目页](https://wenlixiao.com/self-improve-VLA-PLD)。

NVlabs ENPIRE 确有迁入的真机 PLD actor/learner runtime，但 README 明确模型权重和数据需另外准备；开源运行入口不等于完整任务冷启动资源包。[官方代码说明](https://raw.githubusercontent.com/NVlabs/ENPIRE/main/enpire/policy/pld/runtime/README.md)。

## 面向当前条件的实施关口（设计建议）

1. 先实测基础策略：记录到达对象、抓取、进入关键接触、完成任务、恢复可继续练习状态的阶段表现，不只统计整任务成功率。
2. 若缺少基本行为，先短程示范/接管引导，配合可利用成功示范与人类纠正的完整动作空间 RL 或 SFT。示范条数按覆盖和闭环表现停止，不把其他论文的条数当保证。
3. 初期先把一个方向与失败恢复做可靠，再让两方向逐步接入自主循环；不要假设两个近零策略相互执行就能自动形成可持续课程。
4. RLT/DSRL 在具备有用动作基础后同预算比较；PLD 留作恢复数据的回流策略。应以每单位人工时间的成功学习进展和有效循环数排名。

区分：**没有本地任务 SFT ≠ 没有相关任务预训练；0 次观察到成功 ≠ 数学上的成功概率为 0；低整任务成功率 ≠ 所有子技能都没有。** 本轮未发现三者能在用户所述最弱条件下保证自主冷启动的证据。
