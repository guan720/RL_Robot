# 专家汇报稿三轮检查

本任务是将已审查的开发方案改写为专家汇报，不重新开展候选算法选型。每轮冻结主稿和三张图的 Mermaid、SVG、PNG，共十个输入文件。

每轮启动三名新的独立审查者：来源与核心内容；汇报逻辑与验证计划；图文一致与流程边界。先读取冻结稿及原开发材料，再提出八个具体检查问题；图文审查者实际查看图像。每人记录源文定位、判断及必要修改，不读取同轮或历史审查报告。

根审完整阅读报告并合并判断。事实错误、关键遗漏、图文矛盾、误导结论或影响汇报理解的结构问题必须修正；纯可选润色与已明确的待实测问题分开。必要修改或主动采纳任何正文／图修改后重新冻结，连续通过归零。不为达到三轮降低标准。

最后三轮均通过、输入哈希一致且与交付相同后发布。检查只覆盖汇报内容与表达，不宣称新技术实现或实验通过；前次开发文档审查不抵充本次。QA 脚本只核文件和记录，不能替代内容审核。
